# React-Based Webpage Using Figma Design

## Overview

A responsive React.js web application built from a Figma design using Vite. This project focuses on converting a UI design into a fully functional, pixel-perfect, and responsive webpage while maintaining clean code structure and reusable components.

## Features

* Responsive design for desktop, tablet, and mobile devices
* Pixel-perfect Figma implementation
* Reusable React components
* Modern UI layout
* Customer review section
* Services section
* Image gallery section
* Responsive navigation bar
* Clean CSS organization

## Technologies Used

* React.js
* Vite
* CSS3
* Flexbox
* CSS Grid
* Git & GitHub

## Installation

```bash

cd React-based-Webpage-using-Figma-Design/design

npm install

npm run dev
```

```text

```
